# FlowBoard — Kanban Task Board (Starter)

Responsive three-column task board using HTML, CSS and vanilla JavaScript. The design is ready; JavaScript functionality is intentionally left as TODOs.

## Run
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser (Live Server is optional).
4. Complete TODOs in `script.js`.

## Checklist
- [ ] Add a task with title, description, priority and due date
- [ ] Display tasks in To do / In progress / Done
- [ ] Move tasks between columns
- [ ] Edit and delete tasks
- [ ] Keep task counts updated
- [ ] Persist tasks with localStorage
- [ ] Add dark mode
- [ ] Bonus: drag-and-drop

## Concepts
DOM manipulation, forms, arrays/objects, event delegation, conditional rendering, localStorage and optional drag-and-drop.
